# GTA 6 — "caixa sem disco" (Short 9:16)

Vídeo vertical 1080×1920, 30 fps, 57 s, editado em Remotion sobre a narração `public/narracao.mp3`.

- `npm install`
- `npm run dev` abre o Remotion Studio para ajustar a edição
- `npm run render` gera `out/GTA6_sem_disco_9x16.mp4` (áudio normalizado em -14 LUFS)

Legendas palavra por palavra vêm de `src/words.json` (transcrição com timestamps).
Efeitos sonoros e fontes ficam em `public/`, então o render funciona offline.
